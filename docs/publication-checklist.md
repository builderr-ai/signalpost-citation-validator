# Publication checklist

Before creating the public repository:

- [ ] Confirm the GitHub organization and repository name.
- [ ] Confirm public visibility.
- [ ] Keep the MIT licence and contribution terms visible.
- [ ] Inspect every committed file for participant data, credentials, live company content and hidden tests.
- [ ] Verify fixture hashes and expected codes.
- [ ] Confirm the issue says there is no cash bounty and no effect on competition judging.
- [ ] Enable issues and pull requests.
- [ ] Add the prepared citation-validator issue after the repository exists.
- [ ] Record the public repository and issue URLs in the growth ledger.
- [ ] Start the experiment clock only after the issue is live.
