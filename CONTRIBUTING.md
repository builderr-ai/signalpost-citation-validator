# Contributing

Start by commenting on the relevant issue with the part you plan to work on. Keep the first pull request limited to that issue.

For the citation validator:

1. Use Python 3.11.
2. Run entirely offline.
3. Use only synthetic fixtures from this repository.
4. Add focused unit and CLI tests.
5. Keep output deterministic.
6. Explain what the validator proves and what it does not prove.

Do not include participant submissions, hidden tests, credentials, live company data or copied third-party content. Do not make network requests in the validator or its tests.
